🇧🇷 MCP Brasil Gateway

Conecte seus Agentes de IA (Claude Code, Cursor, Windsurf) a Dados Públicos e Comerciais do Brasil

1. Teste Grátis Trial

Gere uma chave de testes imediatamente para experimentar o servidor MCP com 20 créditos inclusos.

2. Recarga de Créditos Pix Automático

Adicione créditos à sua chave. R$ 1,00 = 100 requisições de ferramentas MCP.

3. Como Configurar no Claude / Cursor

Copie o trecho abaixo para o arquivo de configurações do seu agente para começar a usar.

{
  "mcpServers": {
    "mcp-brasil-gateway": {
      "url": "http://localhost:3000/sse?api_key=SUA_CHAVE_AQUI"
    }
  }
}

Para uso via conexão de rede pública, utilize a URL SSE gerada após expor com o túnel.

Ferramentas de Consulta Ativas

Seu agente de IA terá acesso direto a estes comandos estruturados:

  • consulta_cnpj_enriquecida - Dados completos de CNPJ, Quadro de Sócios e Capital Social.
  • consulta_pncp_licitacoes - Busca de oportunidades de compras federais e estaduais ativas no Brasil.
  • consulta_fipe_veiculos_imoveis - Cotação de veículos na Tabela FIPE oficial.
  • cadastrar_alerta_licitacao - Monitoramento inteligente 24/7 de termos de compras públicas.
